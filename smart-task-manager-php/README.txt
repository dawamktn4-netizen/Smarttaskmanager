SMARTTASK AI

Start Apache and MySQL in XAMPP, then open:
http://localhost/smart-task-manager-php/

Existing accounts and tasks are preserved. Do not reset your database.
Fresh install: import database/smart_task_manager.sql through phpMyAdmin.

The complete setup, feature overview, security notes and limitations are in README.md.
Thesis support: docs/THESIS_ALIGNMENT.md, docs/AI_DESIGN.md,
docs/DEMONSTRATION.md and docs/EVALUATION_PLAN.md.

The AI runs locally as an explainable expert system. No API key is required.
Reminders deliver while the application is open; no background email/SMS is included.
